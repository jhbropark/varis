# K-Culture Sample Work Concept

> 30-second loop sample demonstrating VARIS curriculum outcomes with K-culture visual elements

## Purpose

Create a **30-second looping visual piece** that:
1. Demonstrates what learners can create after completing the VARIS curriculum
2. Incorporates K-culture visual elements recognizable to international audiences
3. Shows the AI 3D production pipeline taught in the courses
4. Serves as portfolio evidence for partner outreach

---

## Concept: "Seoul Pulse" (서울의 맥박)

### Theme
A seamless loop showing Seoul's visual culture transformed through AI 3D techniques:
- Traditional patterns morphing into digital particles
- K-pop stage aesthetics with MetaHuman presence
- Urban Seoul skyline with media facade elements

### Visual Breakdown (30 seconds, loop)

| Time | Element | Tools Demonstrated | K-Culture Reference |
|------|---------|-------------------|---------------------|
| 0-5s | Traditional dancheong (단청) pattern | Midjourney + Blender | Korean temple art |
| 5-12s | Pattern dissolves into particle simulation | Houdini growth sim | - |
| 12-20s | MetaHuman emerges from particles | Unreal + MetaHuman | K-pop idol aesthetics |
| 20-25s | Urban Seoul backdrop with LED facades | AI compositing | Gangnam/Coex media walls |
| 25-30s | Camera pulls back, loops to pattern | Full pipeline | - |
